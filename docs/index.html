What do these words mean?

Waiting time = time spent in the ready queue (turnaround minus burst). Turnaround = finish minus arrival. Response = first time on the CPU minus arrival. Context switch = the CPU moves straight from one process to a different one. Quantum = how long Round Robin lets a process run before the next one gets a turn.
